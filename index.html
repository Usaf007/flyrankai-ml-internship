Refresh / Content Opportunity Scoring

Author: Yousaf Atiq | Track: Machine Learning

Abstract

How can search engineering teams accurately detect web pages before they completely lose their organic rankings? This paper presents a machine learning approach using raw traffic and engagement metrics from 240,691 page records in the FlyRank March 2026 warehouse split. I trained a Random Forest Classifier using features such as Search Console impressions, clicks, GA4 sessions, content age, and word count to predict page decay (average position > 10). Evaluated on an 80/20 train-test holdout set, the model achieved a ROC-AUC of 0.7984 compared to 0.5921 for the Week 4 heuristic baseline. The final output is an automated, prioritized action queue that enables editorial teams to optimize their content refresh pipeline with high confidence.

Introduction / Problem Statement

This work supports the editorial decision of which decaying web pages should be prioritized for content refreshes. The unit of analysis is a single web page on a specific reporting date. If the model incorrectly flags a healthy page (False Positive), engineering time is wasted rewriting it. If the model misses a decay (False Negative), the client loses organic traffic and revenue. Machine learning improves this process by evaluating non-linear interactions across traffic metrics and content age simultaneously.

Data

  • Release: FlyRank Internship Warehouse (March 2026 split).
  • Tables: fact_content_daily_performance joined with dim_content.
  • Exclusions & Safety: Explicitly excluded records where ga4_data_available IS FALSE to eliminate zero-filled null sessions. Deliberately removed product-derived flag columns to prevent label leakage. All data is public-safe with no client-identifying names, domains, or credentials included.

Methodology

  • Features: gsc_impressions, gsc_clicks, ga4_sessions, age_days, word_count.
  • Label Definition: target_is_declining = 1 if gsc_avg_position > 10 else 0.
  • Baseline: The Week 4 Heuristic Action Score (age_days * LN(impressions + 1)).
  • Validation Design: Standard 80/20 train-test split. Both the Baseline and ML model were evaluated strictly on the exact same 20% holdout split to prevent leakage.

Results

The Random Forest Classifier successfully captured complex engagement drops that the linear heuristic missed, resulting in a +34.83% lift in discrimination accuracy.

Limitations & Honest Framing

This is an observational, directional study designed for decision-support. I can predict which pages are decaying, but I cannot claim that refreshing them will cause a guaranteed ranking recovery. Furthermore, this model identifies correlations between user engagement signals and ranking drops; it does not reverse-engineer Google's algorithm.
